# Brand assets

This folder contains the assets used to present OpenCorpFilings on GitHub:

- [Logo](logo/opencorpfilings-logo.svg) for light backgrounds.
- [Logo for dark backgrounds](logo/opencorpfilings-logo-on-dark.svg).
- [Social preview](social/opencorpfilings-social.png), 1280 × 640 pixels,
  for the repository's social preview setting.

The documentation site's logo and favicon are in `docs/assets/brand/`.
SVG lettering is outlined and does not require an installed font. The
wordmark uses Outfit, distributed under the SIL Open Font License 1.1.

Preserve the assets' proportions and colours, and leave space around the
mark. Use them to identify the project without implying endorsement by a
regulator or SourceState.
