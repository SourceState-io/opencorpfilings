# Source access and document rights

OpenCorpFilings retrieves individual public records from their source. Its
MIT license covers this library's code, **not** filings, taxonomies, logos or
other material returned by a provider. Users retain the source URL and original
metadata so they can attribute a record and assess their own downstream use.
The package does not redistribute a filing corpus or bundle source documents.

This is a source-policy snapshot reviewed on 2026-10-07, not a grant of rights
or a substitute for the current source terms.

Provider request pacing is a per-client safeguard, not a global quota manager.
If several processes or products share an account or IP address, their combined
traffic must stay within the source's limits. Authentication values should be
provided through environment variables or explicit constructor arguments and
must never be committed or printed.
The optional local response cache stores bounded individual GET results in a
user-chosen directory for five minutes by default. It honors source `no-store`
and shorter freshness instructions, and does not bundle cached records with
the library. Users control storage and removal of their local cache.

`filing.text()` and `filing.facts` are transformations of source material. Their
provenance points back to the original filing/document and does not imply that
the regulator produced the transformed representation.
Optional PDF text preserves the original document URL and page number. Empty
text on an image-only page is not evidence that the page contains no content.
